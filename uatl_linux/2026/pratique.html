Aspects pratiques de l’activité

Jacquelin Charbonnel et Bruno Menan.
Vous n’avez pas encore utilisé Linux, alors comment commencer ? Voici quelques éléments de réponse.

L’activité Linux expérience est orientée pratique. Pendant les séances, vous allez donc manipuler sur ordinateur. Et pour cela, vous avez plusieurs possibilités. Vous pouvez venir avec :

  1. un PC portable sous Linux,

  2. un PC portable à recycler,

  3. un PC portable sous Windows.

PC portable sous Linux

Vous possédez déjà un PC portable sous Linux, c’est parfait, venez avec.

PC portable à recycler

Vous avez un PC portable ancien, qui ne supporte plus Windows (comme moi), et vous voulez lui donner une seconde vie. Profitez de cette activité pour installer Linux (attention, le disque sera reformaté à l’installation, pensez donc à sauvegarder les données avant si nécessaire).

PC portable sous Windows

Si votre version de Windows le permet, vous pouvez suivre les recommandations de Microsoft en utilisant WSL, le sous-système Windows pour Linux. Vous aurez alors un Linux dans votre Windows.

Sinon, si vous souhaitez laisser votre Windows intact, alors vous avez 2 autres solutions :

  • démarrer votre PC à partir d’une clé USB contenant un système Linux. Dans ce cas, vous n’utilisez ni votre Windows, ni son disque, tout se passe en mémoire vive. Si vous choisissez cette option, alors venez à la première séance avec une clé USB (4Go minimum) qui sera reformatée.

  • démarrer un Linux dans votre navigateur web (via par exemple https://distrosea.com/fr).

    L’inconvénient de ces 2 solutions est la perte de votre travail à la fin de chaque séance (car tout est volatile).

Notre recommendation

Pour ceux qui n’ont encore de PC sous Linux, le mieux est de venir avec un portable à recycler (dont vous pourrez reformater le disque). Et ce n’est pas grave si le PC est ancien et lent : Linux est moins gourmand que Windows. Pensez aussi aux PC d’occasion…​
